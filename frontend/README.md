# Frontend — Research Workspace & Dashboard

This directory will host the client-side user interface for the CMLRE Marine Data Platform.

## Planned Technology Stack
- React
- Vite
- Tailwind CSS
- Three.js (for 3D marine globe and spatial exploration)

## Future Responsibilities
- Interactive Research Workspace and Multi-Parameter Dashboard
- 3D Marine Globe and Bathymetry / Species Location Mapping
- Study Workbench (Otolith, eDNA, and Taxonomic Exploration)
- Natural Language & RAG Query Interface
- Academic PDF Report Generation & Export
