# Data Pipeline — Ingestion, Validation & Standardisation

This directory will host data ingestion pipelines, format converters, schema mappers, and quality control workflows.

## Future Responsibilities
- File upload handling and format detection (CSV, TSV, NetCDF, CTD, FASTA, Darwin Core)
- Schema standardisation and unit conversion
- Data Quality Control (QARTOD-style oceanographic QC, missing values, range and consistency checks)
- Metadata extraction, provenance recording, and staging for unified persistence
